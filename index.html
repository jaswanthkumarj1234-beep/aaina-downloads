AAINA

SMART MIRROR FOR CLOTHING SHOPS

Android phone or tablet

Tap the button. The app downloads straight to your phone.

Download for Android (APK)
  1. Open the downloaded file. If asked, allow installs from your browser.
  2. Open Aaina Mirror, allow the camera.
  3. Tap the AAINA logo 5 times, paste your API key(s), and save.

Windows laptop or PC

For a TV or big screen connected by HDMI. Use any webcam.

Download for Windows (installer)
  1. Run the file. If Windows says "unknown publisher", choose More info, then Run anyway.
  2. Tap the AAINA logo 5 times, paste your API key(s), pick your camera, and save.
  3. F11 = full screen on/off. Ctrl+Q = quit.
